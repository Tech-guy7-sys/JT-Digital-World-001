JT DIGITAL WORLD — SETUP CENTER + APP INSTALL WIZARDS

START HERE (Windows):
1. Extract this ZIP.
2. Double-click Setup-Wizard\START-JT-SETUP.bat.
3. Click Check PC, then install missing build tools if needed.
4. Configure local AI options and the source/install path.
5. Select Build all 9 Windows installers and click INSTALL JT DIGITAL WORLD.
6. After the build succeeds, open Build\release\individual and run each .exe you want. Each app's NSIS installer opens its own guided setup wizard and creates app shortcuts.

The products include Agent Jeff (desktop agent), Jeff AI, JT Studio, JT Stream, JT Cloud, JT Design, JT Code, JT Motion, and JT App Manager. The public website is separate from these apps.

This source ZIP does not contain prebuilt signed .exe files. Production website sign-in and downloads require the Cloudflare D1 binding and published release artifacts; follow PRODUCTION-SETUP-SIGNIN-DOWNLOADS-DEPLOYMENT.md.
